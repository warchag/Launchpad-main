Launchpad for macOS

แอปพลิเคชัน Launchpad แบบเนทีฟระดับ 120Hz ProMotion ถอดแบบความรู้สึกดั้งเดิมของ Apple
ผสานดีไซน์ Frosted Glass จากวอลเปเปอร์จริง ค้นหา 2 ภาษาทันใจ และจัดระเบียบแอปครบวงจร

ดาวน์โหลด Launchpad.app (.zip) Releases บน GitHub
⚡ Swift 6 & SwiftUI • 🍏 Apple Silicon (M1-M5) & Intel Mac • 📦 ขนาดไฟล์ ~5.2 MB

Key Features

ประสิทธิภาพระดับเนทีฟ ดีไซน์ที่คุ้นเคย

ออกแบบมาเพื่อความเร็วและความลื่นไหลสูงสุด ทำงานกลมกลืนกับ macOS ดั่งแอปของระบบ

✨

120Hz ProMotion & Gesture Lock

รองรับอัตราการรีเฟรช 120Hz พร้อมระบบ Gesture Lock อัจฉริยะ ล็อก 1 การปาด Trackpad ต่อ 1 หน้า ป้องกันหน้าไหลข้ามจากแรงเฉื่อย

🖼️

Real-time Frosted Wallpaper

ดึงภาพวอลเปเปอร์หน้าจอปัจจุบันมาเรนเดอร์เอฟเฟกต์ Gaussian Blur ด้วย GPU Caching ประหยัดพลังงานและให้มิติกระจกฝ้าเสมือนจริง

📐

ตารางมาตรฐาน 7 × 5 (35 แอป/หน้า)

คำนวณระยะห่าง Responsive อัตโนมัติ รองรับจอ MacBook ที่มี Notch, iMac รวมถึงจอภาพภายนอกระดับ 4K / 5K อย่างสมบูรณ์แบบ

🔍

Type-to-Search ทันใจ 2 ภาษา

พิมพ์ค้นหาได้ทันทีโดยไม่ต้องคลิกช่องค้นหา รองรับชื่อภาษาไทย ชื่อไฟล์ .app ภาษาอังกฤษ และค้นหาด้วยตัวย่อ เช่น พิมพ์ "vsc" สำหรับ VS Code

🗂️

การจัดการโฟลเดอร์ครบวงจร

ลากแอปทับกันเพื่อสร้างโฟลเดอร์ ลากสลับตำแหน่งได้อิสระ ลากแอปออกจากโฟลเดอร์ หรือกดปุ่ม "สลายกลุ่ม (Ungroup)" นำแอปกลับสู่หน้าหลักในคลิกเดียว

⭐

Favorites Mini Dock & Live Status

แถบกระจกฝ้าด้านบนรวมแอปโปรดและแอปเปิดล่าสุด พร้อมไฟสถานะแสดงแอปที่กำลังเปิดทำงานอยู่จริง และคลิกขวาเพื่อสั่ง Quit แอปได้ทันที

Screenshots

สำรวจฟีเจอร์ผ่านหน้าจอการใช้งานจริง

คลิกเพื่อดูภาพความละเอียดสูงในแต่ละมุมมองของโปรแกรม

หน้าจอหลักมาตรฐาน Apple 7 คอลัมน์ × 5 แถว

พื้นหลัง Frosted Glass จากวอลเปเปอร์จริง แถบหมวดหมู่แอป และจุดไฟแสดงแอปที่กำลังทำงาน

Glassmorphic Folder View & Drag-to-Reorder

เปลี่ยนชื่อโฟลเดอร์ ลากจัดลำดับแอปภายใน ลากแอปออกนอกกรอบ หรือกดปุ่ม Ungroup เพื่อสลายกลุ่ม

Type-to-Search & Keyboard Arrow Navigation

พิมพ์หาได้ทันทีโดยไม่ต้องคลิก เลื่อนกรอบโฟกัสด้วยปุ่มลูกศร และกด Return เพื่อเปิดแอปทันที

Bilingual Unified Settings (TH / EN)

ปรับขนาดไอคอน ความเบลอพื้นหลัง ตั้งปุ่มลัด มุมจออัจฉริยะ Hot Corner และการสั่น Haptic

Installation

วิธีติดตั้งใน 3 ขั้นตอนง่ายๆ

ไม่ต้องตั้งค่าระบบให้ยุ่งยาก เพียงลากไฟล์ลงในเครื่องก็พร้อมใช้งานทันที

01

ดาวน์โหลด & แตกไฟล์

ดาวน์โหลดไฟล์ Launchpad.zip จากหน้าเว็บนี้ แล้วดับเบิลคลิกเพื่อแตกไฟล์ จะได้รับตัวโปรแกรม Launchpad.app

02

ลากเข้า Applications

ลากไฟล์ Launchpad.app ไปวางไว้ในโฟลเดอร์ /Applications ของเครื่อง Mac เพื่อติดตั้งอย่างถูกต้อง

03

ปักหมุดไว้ที่ Dock

ลากไอคอนจาก Applications ลงมาวางบนแถบ Dock ด้านล่างเพื่อกดเปิดใช้งานได้สะดวกตลอดเวลาเหมือน Launchpad ดั้งเดิม

⚠️
คำแนะนำเรื่องความปลอดภัย (macOS Gatekeeper):

เนื่องจากเป็นแอปแจกจ่ายภายนอก Mac App Store หากเปิดครั้งแรกแล้วระบบแจ้งเตือนว่า "แอปมาจากนักพัฒนาที่ไม่สามารถระบุตัวตนได้" ให้คลิกขวาที่ตัวแอปแล้วเลือก Open หรือเปิด Terminal แล้วรันคำสั่งปลดล็อกด้านล่าง:

$xattr -cr /Applications/Launchpad.app
